# UX-0003, exercício ativo e timer global

## Objetivo

Separar a lista da rotina da execução do exercício e manter o descanso visível enquanto o usuário navega pelo aplicativo.

## Entregas

- UX-0003 como lista compacta da rotina, sem expansão inline.
- UX-0009 como tela individual do exercício ativo.
- Timer global com retorno ao exercício de origem.
- Testes unitários para a contagem baseada em `endsAt` e fluxo visual mobile atualizado.

## Verificação

- `pnpm test`
- `pnpm lint`
- `pnpm build`
- `pnpm visual:check`
